IActionResult means:

This method returns an HTTP response.

Examples of HTTP responses:

return Ok(response);        // 200 OK
return NotFound();          // 404 Not Found
return BadRequest(error);   // 400 Bad Request
return Created(...);        // 201 Created
return NoContent();         // 204 No Content

/////////////////////////////////////////////////////////////////////////////////////////////////////////

Task means:

This method is asynchronous and will finish later.

Because your controller calls the database through the service:

await _categoryService.GetAll();

Database work takes time, so we use:

async Task<IActionResult>

Meaning:

This method will eventually return an HTTP response.
